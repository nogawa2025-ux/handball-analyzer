# ハンドボール分析

ベンチでスマホから試合をリアルタイムに記録し、シュート率や弱点を分析するWebアプリです。

## 使い方

1. ⚙設定で自チーム名と選手（「背番号 名前」を1行ずつ）を登録
2. 「新しい試合を記録」→ 対戦相手を入力して開始
3. 攻撃中のチームを選び、シュートした場所をコート図でタップ → 選手 → 結果（得点／GKセーブ／枠外・ブロック）
   - 種類（セット／速攻／7m）とコース（ゴール9マス）は必要なときだけ
   - 記録すると攻撃チームが自動で切り替わる
4. ターンオーバー・2分退場はボタンから選手をタップ
5. 「試合終了・分析を見る」で、概要・シュートマップ・選手・GK/コース・弱点を確認
6. 「LINEなどで共有」で分析リンクを送れる（受け取った人は開くだけで見られる）

### 試合前の相手分析（スカウティング）

1. 「新しい試合を記録」で「スカウティング」を選び、分析するチームとその対戦相手を入力
2. 記録のしかたは同じ（分析するチームの攻撃だけでもOK。相手GKの傾向も見たいときは、もう一方のチームのシュートも記録）
3. ホームの「相手チーム分析（試合前）」で学校名を選ぶと、スカウティングと自チームの試合をまとめたレポートが見られる
   - 警戒すること／狙いどころ、要注意選手（よく打つエリア・よく決めるコース）、7mの担当、攻撃の傾向、GKが破られやすいコース

学校名は試合ごとに同じ表記で入力してください（入力欄に過去の学校名が候補として出ます）。

データは記録したスマホのブラウザ内に保存されます。⚙設定からバックアップできます。

## 公開について

共有リンクを他の人が開くには、このフォルダをWeb上に公開する必要があります（例: GitHub Pages、無料）。
公開したURLをスマホで開き、「ホーム画面に追加」するとアプリとして使え、オフラインでも動きます。

## 開発

- ビルド不要（HTML / CSS / JavaScript のみ）
- ローカル確認: `python -m http.server 8765` → http://127.0.0.1:8765/
- テスト: `npm test`
